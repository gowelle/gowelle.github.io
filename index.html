// featured

The app I built because my Mac refused to retire.

Paddock

A local PHP and Laravel environment for Intel Macs that works the moment it is installed. A native menu bar app, a background service and a command-line tool, written in Swift.

  • Every project folder served at its own .test address, with trusted HTTPS
  • PHP, databases, a mail catcher and Xdebug built in
  • Windows for mail, logs and dumps
  • One command to install, and it updates itself
Visit Paddock Source

// how I work

Things I believe about software.

  1. It should work the moment you install it.Every set-up step is a place to lose someone.
  2. Tools for getting started should be free.Nobody should pay for the ground they stand on.
  3. Software shouldn't ask what it can find out.If the answer is on the machine, go and look.
  4. "Works on my machine" is where testing starts.It is not where it ends. I've checked.
